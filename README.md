This repository contains workflows for recalculating values provided in the BioShifts v2 database and BioShiftR R package.

Here, we use one target article to demonstrate:
1. the calculation of climate velocity using the target polygon and gridded climate data
2. the calculation of spatial summary values using the target polygon
3. taxonomic harmonization of species names as provided in source articles
4. standardization of range shift rates as reported in source articles
